# Charm the Commuter: Forecast a City That Isn't

One line of weather forecast, at most 140 characters, for a city that does not exist — written to make a bored commuter smile on the way to work. The entry forecasts light rain clearing to sunshine for Quillwater, an invented city, where the number 12 tram is finally on time.

## Run it

```sh
python3 main.py
```

This writes the single forecast line to `/output/entry.txt` (validated first: 1–140 characters, UTF-8, not whitespace-only, no control characters). Deterministic — no network, no randomness, no secrets.
